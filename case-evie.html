EVIE, an on-premise local LLM and classroom assistant

An on-premise, custom-built, in-house local LLM and classroom assistant. It is complete and in active use. I continue to add updates and iterations so a class can get in-room help without sending classroom audio to a cloud model.

Role. Designer and builder Users. In-room classroom support Status. Complete, in active use, with ongoing updates. 2025 to present Stack. Ollama, Qwen 2.5 32B, local speech pipeline

Problem

High school AI class sessions need a voice assistant that can answer in the room. Sending classroom audio or student questions to a cloud model is the wrong default in that setting. EVIE, the Educational Virtual Intelligence Engine, is a single always-on rig: wake word, local speech to text, a local language model with a custom personality, spoken replies, a classroom display, and lighting that shows state.

My responsibility

I designed and built the system as a custom in-house assistant, chose a fully local inference path, and I continue to ship updates and iterations using Claude Code and GitHub. The important decisions were to keep audio and generation on the machine, to use a custom personality model with topic-redirection rules, and to use a local retriever rather than a hosted vector database. Those choices favor privacy and a system I can operate and improve in a classroom.

What I delivered

The documented pipeline is orchestrated by a listener script. After a wake word or a hotkey, audio is recorded until a silence gate, transcribed, and routed to teacher-assist phrases, memory commands, a local joke bank, or a general query. The general path may attach retrieved local notes. Ollama generates a reply. A local text-to-speech service speaks it. The display and lights follow listening, thinking, and speaking states. Memory and daily transcripts are stored in two separate local SQLite databases.

Lights show green when listening, purple when thinking, and cyan when speaking. Safety rules live in the model system prompt, keeping the stack fully on-premise. The documented default for speech to text is openai-whisper; a faster-whisper option also exists.

In the current system

Wake word (custom openWakeWord model, with a transcription fallback), speech to text, local Ollama model (customized Qwen 2.5 32B), local text to speech, classroom GUI, Nanoleaf state lighting, SQLite memory and sessions, and a CPU retriever over local text.

Next build and expansion

OAK camera vision, bilingual tutoring, and a larger curriculum corpus.

Results

EVIE is complete and in active use as the classroom assistant I built. The in-room loop (wake word, speech to text, local language model, spoken replies, display, and lights) is live and continually updated.
